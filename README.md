## ✨ Fonctionnalités

- 🎣 **Mode "Pêche"** — expérience d'accueil originale et ludique pour découvrir le portfolio
- 🎨 **Mode classique** — navigation directe pour les visiteurs pressés
- 🔐 **CryptoLab** — outil pédagogique interactif (César, Vigenère, Hill) avec terminal animé
- 🌍 **Bilingue FR/EN**
- 📱 **100% responsive**
- 📄 **CV téléchargeable** en un clic
- 🚀 **Déploiement continu** via Vercel

## 🚀 Installation locale

```bash
# Cloner le repo
git clone https://github.com/YangtozoR59/portfolio.git
cd portfolio/portfolio

# Ouvrir simplement index.html dans le navigateur
# ou lancer un petit serveur local
npx serve .
```
