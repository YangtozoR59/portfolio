Jeu de la Vie

Expérimentez avec les automates cellulaires

Règles du Jeu (Conway)
Le Jeu de la Vie est un automate cellulaire. Chaque cellule de la grille est soit vivante, soit morte.
1. Sous-population : Une cellule vivante avec moins de 2 voisins meurt.
2. Surpopulation : Une cellule vivante avec plus de 3 voisins meurt.
3. Survie : Une cellule vivante avec 2 ou 3 voisins survit.
4. Reproduction : Une cellule morte avec exactement 3 voisins devient vivante.

Cliquez sur la grille pour modifier les cellules.
